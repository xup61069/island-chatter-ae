Island Chatter AE
================================================

安裝：雙擊 Install.bat，跳出使用者帳戶控制的視窗時按「是」。
      安裝前請先完全關閉 After Effects。
      裝好後開啟 After Effects，選 Window > IslandChatterNativePanel.jsx。

移除：雙擊 Uninstall.bat。

resources 資料夾放的是外掛本體與安裝腳本，不用手動去動它。
授權條款見 LICENSE，第三方資料聲明見 resources\THIRD_PARTY_NOTICES.md。
原始碼與完整說明：https://github.com/xup61069/island-chatter-ae

------------------------------------------------

Install: double-click Install.bat and accept the User Account Control prompt.
         Close After Effects completely first.
         Then start After Effects and open
         Window > IslandChatterNativePanel.jsx.

Remove:  double-click Uninstall.bat.

The resources folder holds the plug-in itself and the install scripts; there is
nothing in there you need to touch. See LICENSE for terms and
resources\THIRD_PARTY_NOTICES.md for third-party data notices.
