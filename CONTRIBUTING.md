# Contributing

Thanks for helping improve Island Chatter.

1. Open an issue for substantial changes so the design can be discussed first.
2. Keep the runtime dependency-free and compatible with After Effects ExtendScript (ES3-era syntax).
3. Run `npm test` before submitting a pull request.
4. Do not add copyrighted game audio, extracted assets, character art, or trademarks as branding.
5. Describe which After Effects version and operating system you tested.
