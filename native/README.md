# Island Chatter native audio effect

This directory contains the Windows native-audio plug-in work. The DSP library is independent of Adobe headers so it can be compiled and tested before the After Effects SDK is installed.

## Current status

- Portable C++17 CV speech synthesizer: implemented
- Deterministic block/random-access audio output: implemented
- Native tests and WAV renderer: implemented
- Unicode Unihan Mandarin readings for 44,355 Han characters: implemented
- Mandarin initials, finals, nasal codas, diphthongs, aspiration, and tone contours: implemented
- Stable After Effects parameter ABI and SDK validation: implemented
- After Effects audio effect entry point and PiPL: implemented
- Windows x64 `.aex` build against AE SDK 25.6: verified
- Direct text-layer synthesized audio with no generated files: implemented

## Build and test the DSP

From a Visual Studio x64 developer prompt:

```powershell
cmake -S native -B native/build -G Ninja
cmake --build native/build --config Release
ctest --test-dir native/build -C Release --output-on-failure
native/build/island_chatter_render.exe native-preview.wav
```

## Build the `.aex`

Download the current After Effects SDK from the [official Adobe Developer Console](https://developer.adobe.com/console/servicesandapis/ae), extract it, then configure with:

```powershell
cmake -S native -B native/build-ae -G "Visual Studio 17 2022" -A x64 `
  -DISLAND_CHATTER_BUILD_AE_PLUGIN=ON `
  -DAE_SDK_ROOT=C:/path/to/AfterEffectsSDK
cmake --build native/build-ae --config Release
```

The Adobe SDK is not redistributed by this repository.

The resulting plug-in is `native/build-ae/plugin/Release/IslandChatterNative.aex`. Install it under the After Effects `Support Files/Plug-ins` directory. Install `panel/IslandChatterNativePanel.jsx` under `Support Files/Scripts/ScriptUI Panels`, restart After Effects, then open the panel from the Window menu.

## Mandarin input

Traditional and Simplified Han characters are looked up in Unicode's `kMandarin` data. The synthesizer models Mandarin's aspirated/unaspirated stop and affricate contrast instead of treating pinyin `b/d/g` as English voiced stops. It also distinguishes the `j/q/x`, `zh/ch/sh`, and `z/c/s` groups, supports `ü`, diphthong movement, `-n`/`-ng` endings, and four tone contours plus neutral tone.

`native/generated/mandarin_readings.hpp` is generated by:

```powershell
node native/tools/generate-unihan-map.js `
  path/to/Unihan_Readings.txt `
  native/generated/mandarin_readings.hpp
```

See `THIRD_PARTY_NOTICES.md` for the Unicode data license.

## Helper panel contract

`panel/IslandChatterNativePanel.jsx` puts `Island Chatter Native` directly on the selected text layer. Because AE 26.0 crashes in `BEE_RenderItemSound` before a third-party synthesized-audio callback receives a text layer, the panel places AE's built-in Tone effect immediately before Island Chatter as a zero-level sound-source bootstrap. Island Chatter then replaces every output sample. This requires no carrier layer and generates no WAV files.

The panel writes Source Text into 64 hidden UTF-16 numeric parameters when Apply is clicked. After editing Source Text, click Apply again.

Voice, Pitch, Speed, Volume, and Initial are keyframeable, but they are meant to be set once per layer. After Effects passes an audio effect one parameter snapshot per audio block, so an animated value re-synthesizes the whole utterance for every block, and animating Speed shifts each syllable's start time enough to step audibly at block boundaries. Animate the layer's own Audio Levels for volume moves.

The panel's `estimateSpeech()` mirrors the engine's text planning, including the CJK punctuation block, surrogate pairs, tone sandhi, and the phrase and neutral-particle tables. `npm test` fails if the two drift apart.

The optional pronunciation field accepts tone-number pinyin (`ni3 hao3`), space-delimited Zhuyin (`ㄋㄧˇ ㄏㄠˇ`), or inline overrides such as `[重|chong2]新`. Phrase-level readings handle common polyphones such as 音樂/音乐, 銀行/银行, 重新, 重要, 長大/长大, and 還書/还书. The language planner also applies third-tone, 一, and 不 sandhi plus common neutral-tone particles.

The panel can batch-apply the effect to every selected text layer, fit layer duration, and rebuild only its own `IC:` markers. Optional animation controls create keyframed `IC Mouth`, `IC Volume`, `IC Pitch`, `IC Head Bounce`, and `IC Blink` sliders for character rigs. Type-On adds a dedicated text animator and leaves the Source Text property intact. After editing Source Text, press Apply again to synchronize the audio and timing data; the panel deliberately avoids background polling because AE refuses scheduled scripts while a modal dialog is open.

The first five visible effect parameters are Voice, Pitch, Speed, Volume, and Consonant. Parameter 6 is the hidden text length and parameters 7-70 hold UTF-16 code units. The native `.aex` must keep this order stable.
